# Λεξοδρόμιο

Αυτοτελής, στατική web εφαρμογή για το παιχνίδι ανάγνωσης.

## Άνοιγμα

Άνοιξε το `index.html` σε σύγχρονο browser σε Mac, Windows, κινητό ή tablet. Δεν απαιτείται εγκατάσταση ή λογαριασμός.

## Περιλαμβάνει

- Εισαγωγή κειμένου και κουμπιά για κάθε λέξη, με τη σειρά του κειμένου.
- Παιχνίδι διαχωρισμού ανά γράμμα ή ανά συλλαβή, με χειροκίνητη διόρθωση συλλαβών.
- Οριζόντιο, απαλό κυματιστό δρόμο με χρωματιστά κελιά, οριζόντια κύλιση όπου χρειάζεται, σύρσιμο του αυτοκινήτου και οθόνη επιτυχίας.
- Τοπική αποθήκευση κειμένων με δυνατότητα ανοίγματος και διαγραφής.

Τα αποθηκευμένα κείμενα μένουν στον συγκεκριμένο browser και τη συγκεκριμένη συσκευή. Δεν συγχρονίζονται μεταξύ συσκευών. Η εφαρμογή δεν έχει δημοσιευτεί σε hosting.
